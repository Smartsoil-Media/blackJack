# Putt Lab

A neon-midnight score keeper for a 2 / 4 / 6 / 8 ft putting mat. Installable as a
home-screen app (PWA), works offline, keeps everything in the browser's local storage.

## Games
- **Free Practice** – pick a distance and a target (cup or marker), log every putt.
- **Ladder** – start at 2 ft, a make steps you back a line, a miss steps you forward. Hole the 8-footer to finish. Fewest putts wins.
- **Race to 21** – rotate 2, 4, 6, 8. A make scores 1 / 2 / 3 / 4 points by distance. Reach 21 in the fewest putts.
- **Lag Ladder** – from the cup end, lag out to each line, three balls each. Dead on = 3, just short or long = 1. Perfect is 36.

## Run it
Live at https://smartsoil-media.github.io/blackJack/putting-mat/ via GitHub Pages. Open it in Safari or Chrome, then
"Add to Home Screen". Files: `index.html` (app), `manifest.webmanifest`, `sw.js`, `icons/`.
